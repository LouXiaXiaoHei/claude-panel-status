# Claude Panel Status 图标重设计规格

## 目标

为 VS Code 扩展 Claude Panel Status 重新设计市场图标，替换现有三条彩色胶囊图形。新图标需在扩展市场、扩展列表和小尺寸界面中保持清晰、独立且易辨认，并避免让用户误以为这是 Anthropic 官方产品。

## 最终视觉方向

采用「状态透镜」概念与「柔和 3D」质感：

- 深色圆角方形底座提供稳定轮廓，并适配浅色与深色界面。
- 中央为带微高光的信号芯片，表达扩展对 Claude Code 面板状态的持续感知。
- 外围使用分段仪表环，表达模型、分支、上下文、推理强度与成本等多维状态。
- 状态环由青色、紫色和金色组成；右上方使用绿色在线状态点。
- 材质使用克制的微高光、浅阴影和有限辉光，不使用强霓虹、复杂纹理或写实场景。

## 品牌与内容约束

- 不使用 Claude 或 Anthropic 的官方标志、字标、字母缩写或近似官方造型。
- 不包含任何文字、数字、水印、背景场景或装饰性小物件。
- 保持构图居中、轮廓完整，并为四周保留安全边距。
- 颜色不可依赖单一界面背景；图标自身必须形成完整视觉边界。

## 生成与文件处理

- 使用内置图片生成工具生成高分辨率正方形位图。
- 最终选择的结果缩放为 128×128 像素 RGBA PNG。
- 用户已明确要求替换，因此最终文件覆盖仓库根目录的 `icon.png`。
- 不修改 `package.json` 中的图标路径，因为它已指向 `icon.png`。

## 验证标准

- 检查 128×128、64×64 和 32×32 三种显示尺寸。
- 在 32×32 下仍能区分中央芯片、分段状态环与在线状态点。
- 不出现模糊边缘、过强辉光、不可控文字、品牌标记或明显生成瑕疵。
- PNG 尺寸、色彩模式和透明通道符合现有扩展资源要求。
- 运行现有测试，确认资源替换不影响扩展逻辑。

## 非目标

- 不重做 README 截图、扩展 UI 或状态条样式。
- 不新增动画、SVG 图标系统或主题变体。
- 不调整扩展名称、描述、发布配置或功能行为。
